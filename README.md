# BIM DNA IFC Viewer

Stabilna baza projektu: **Viewer 4.10**.

Ta gałąź (`main`) przechowuje działającą wersję bazową. Rozwój funkcji 5.x będzie prowadzony na osobnej gałęzi.

## Viewer 4.10
- import IFC przez IfcOpenShell,
- wizualizacja WebGL,
- obiektowe zaznaczanie elementów IFC,
- panel właściwości i Property Sets,
- ukrywanie i izolowanie elementów,
- perspektywa i aksonometria,
- nawigacja 3D,
- orientacja Z-up i odniesienie do IfcSite.

Uruchom `START_IFC_VIEWER_4_10.bat`.
